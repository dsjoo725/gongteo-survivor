# 공터서바이버

Phaser·TypeScript·Vite로 만든 자동 사격 생존 게임 프로토타입입니다. 방향키 또는 터치 드래그로 이동합니다.

## 기능·맵 확장 시 참고할 문서

**[디자인·확장 기준서](design/DESIGN_BIBLE.md)**를 공통 기준으로 사용합니다. 사용자가 선택한 3안 ‘달빛의 공터’의 아트·세계관, 모바일 정보 위계, 새 기능·맵 제작 원칙과 검증 방법을 정리했습니다.

- [UI 컴포넌트 규격](design/dream-concept/DESIGN_SYSTEM.md)
- [새 맵 기획 양식](design/templates/MAP_BRIEF.md) · [새 기능 기획 양식](design/templates/FEATURE_BRIEF.md)
- [현재 화면 시안과 실행법](design/dream-concept/README.md) · [전투 확장 계약](design/COMBAT_FOUNDATION.md)

선택한 ‘달빛의 공터’ 아트를 실제 Phaser 게임에 적용했습니다. 달빛 타이틀에서 시작하고, 분리 제작한 플레이어·적이 기존 판정에 따라 움직입니다. [실제 플레이 통합](design/features/moonlight-integration.md)과 [자산·프롬프트](public/art/moonlight/manifest.json)에 적용 범위를 기록했습니다. React 시안은 비교 자료로 보존합니다.

달빛 통합의 전체 테스트 172개와 최종 빌드가 통과했습니다. Chromium에서 타이틀 진입·전투·강화·사망·재시작과 세로·가로 화면을 확인했습니다. [전투 캡처](artifacts/moonlight-combat-mobile-390.png) · [강화 캡처](artifacts/moonlight-upgrade-mobile-390.png)

## 실행과 빌드

이 폴더에서 실행합니다.

```powershell
npm install
npm run dev
```

터미널에 표시된 로컬 주소를 엽니다. 포트를 지정하려면 `npm run dev -- --host 127.0.0.1 --port 5174`를 사용합니다. 현재 작업 서버는 [localhost:5174](http://localhost:5174)입니다.

```powershell
npm test
npm run build
npm run preview
```

테스트용 Chromium이 없는 경우 `npx playwright install chromium`을 한 번 실행합니다. `dist/`는 정적 빌드 결과이며 외부 배포는 수행하지 않습니다.

## 화면과 조작

- 첫 화면의 **꿈으로 들어가기**로 전투를 시작합니다. 그림 준비 전에는 시작을 막고 실패 시 다시 시도할 수 있습니다. 타이틀 환경설정은 기존 설정을 공유하며 닫으면 타이틀로 돌아갑니다.

- **PC도 모바일처럼 세로 화면**으로 표시합니다. 마우스를 쓰는 브라우저는 창 높이에 맞춘 최대 9:16 화면을 중앙에 놓습니다. 좁은 창에서는 가용 너비를 사용합니다.
- 터치 화면은 가용 화면을 채우며 가로 회전을 지원합니다. 게임 화면 안을 맵이 채우고 페이지 바깥의 스탯창·조작 안내 영역은 없습니다.
- 상단에는 정지 버튼·생존 시간·처치 수, 그 아래에는 오른쪽 끝에 레벨 숫자가 이어지는 금빛 경험치바가 있습니다. 체력은 캐릭터 바로 아래의 짧은 막대로 표시하며 상세 숫자는 전투 화면에서 숨깁니다.
- 방향키 / 터치 드래그로 이동하고 자동으로 사격합니다. 조작 안내는 게임 시작 후 전투 시간 5초 동안만 표시합니다.
- 메뉴 버튼 또는 Esc로 정지합니다. **계속하기 / 플레이어 스탯 / 환경설정 / 다시 시작**을 제공합니다.
- 메뉴·스탯·설정·재시작 확인 중에는 물리·적 생성·탄환·사격·접촉 피해 쿨다운·피격 효과·생존 시간이 모두 멈춥니다.
- 하위 화면에서 Esc는 메뉴로, 메뉴에서 Esc는 전투로 돌아갑니다. 배경을 눌러도 재개하지 않습니다. 닫을 때 포커스는 메뉴 버튼으로 돌아갑니다.
- 메뉴를 열거나 화면 크기가 바뀌면 누른 이동 키와 터치 캡처를 해제합니다. 전투 복귀 뒤 새 이동 입력으로 조작합니다.
- 탭 이탈 정지와 사용자 메뉴 정지를 별도로 관리합니다. 다른 창에 갔다 돌아와도 사용자가 열어 둔 메뉴는 유지됩니다.
- 재시작은 확인 후 현재 기록을 초기화합니다. 게임 오버에서는 버튼 또는 Enter로 다시 시작합니다. 이어하기 저장은 아직 없습니다.

## 경험치와 강화

달빛 성장 UI는 크림색 그림 카드에서 이번에 채울 별 한 칸을 강조합니다. 레벨업 때 이전 바를 짧게 채운 뒤 새 레벨과 초과 경험치를 표시합니다. 320px·390px 세로와 가로 화면, 관련 테스트 34개, 정적 빌드를 확인했습니다. [실제 강화 화면](artifacts/paper-growth-live-choice-390.png)

적을 처치하면 경험치를 얻고, 레벨업 때 최대 3개 카드 중 하나를 골라 스탯을 강화합니다. 카드 순서는 **이름 → 이미지 → 설명 → 별**이며 각 강화는 최대 5단계입니다. 완성된 강화는 후보에서 빠집니다. 선택 중 전투 전체가 멈추고, 선택 후 새 이동 입력으로 복귀합니다. 여러 레벨이 올랐다면 순서대로 고릅니다. 모든 강화 완료 뒤에는 전투를 계속합니다. 성장과 별 단계는 재시작 때 초기화됩니다. [경험치·강화·HUD 구현](design/PROGRESSION_IMPLEMENTATION.md)에 규칙과 참고 화면을 기록했습니다.

성장·HUD 반영 후 전체 테스트 164개를 통과했고, 마지막 문구 정리 뒤 관련 25개 재검증과 빌드도 통과했습니다. PC·터치 세로·가로에서 페이지 오류와 가로 넘침이 없었습니다. [선택 화면](artifacts/xp-choice-mobile.png)과 [전투 HUD](artifacts/xp-hud-mobile.png)를 보존했습니다. 실제 기기와 장시간 밸런스 검증은 별도입니다.

## 환경설정

지원 브라우저에서 전체 화면 모드를 켜고 끌 수 있습니다. PC의 세로 화면 배치는 전체 화면 모드에서도 유지됩니다.

‘피격 효과 줄이기’는 플레이어 피격 시 명도 변화를 줄이고 적의 사망 축소를 0.1초 페이드로 바꿉니다. 기본값은 운영체제의 동작 감소 설정을 따르고 사용자 선택은 이 브라우저에 저장합니다. 저장이 차단되어도 이번 게임에는 적용됩니다. 소리 기능이 없으므로 음량 설정은 제공하지 않습니다.

## 적과 전투 효과

적은 짙은 녹색의 둥근 생명체로 표현한 기본 추격형 한 종류만 등장합니다. 최대 체력은 2여서 기본 공격력 1의 탄환 두 대에 죽습니다. 플레이어 공격력이 달라지면 피해량에 따라 필요한 명중 횟수도 달라집니다. 접촉 피해는 적의 공격력 스탯을 사용하며 기본값은 1입니다. 여러 적에 동시에 닿아도 기존 0.8초 피격 보호를 공유합니다.

공통 8스탯 구조는 유지합니다. 적의 공격 속도는 0으로, 별도 공격 동작·공격 예고·공격 주기·흡혈은 없습니다. 접촉 피해량은 공격력을 따르며 공속과 독립적입니다. 공격력 0은 피해와 피격 보호를 발생시키지 않습니다. 현재 접촉 피해에는 치명타와 흡혈을 적용하지 않습니다. 적 공격력·이동·크기·최대 체력은 공통 스탯을 사용하며 기본값은 `src/enemies.ts`에서 조절합니다.

효과는 미니멀하게 유지합니다. 적 피격은 기본 3px 넉백과 3틱의 짧은 이동 정지로 표현하고, 큰 적은 덜 밀립니다. 넉백 뒤 벽·군중·접촉 판정을 다시 계산하므로 밀어낸 적의 접촉 피해를 잠깐 피할 수 있습니다. 사망은 충돌체를 즉시 제거한 뒤 원래 모습이 0.1초 동안 작아지며 사라집니다. 흰색 플래시·파편·소멸 링은 사용하지 않습니다. 플레이어 피격은 0.12초 동안 원래 색을 약하게 어둡게 하며 조작 위치를 밀지 않습니다.

적 체력은 첫 피격 뒤 가는 막대로 표시합니다. 메뉴를 열면 넉백·사망 축소도 함께 멈춥니다. 화면 회전 시 사망 연출의 위치도 새 전장에 맞춥니다. 실제 플레이에서 가독성과 난이도를 더 조정할 수 있으며, 자동 검증 통과가 재미·장시간 밸런스 검증을 뜻하지는 않습니다.

## 전투 확장 기반

탄환과 움직이는 적의 이동 경로 전체로 충돌을 검사합니다. 공속은 소수 진행도를 누적하므로 초당 60회 이상도 공격량이 증가합니다. 같은 틱의 공격은 경로·치명타 판정을 공유하는 묶음 탄환으로 표현하고, 처치 뒤 남은 공격 횟수는 계속 이동합니다. 기본 공속과 미니멀한 효과는 유지합니다.

기본 스탯 변경과 ID별 효과의 추가·교체·제거·만료를 지원합니다. 최종 스탯은 기본값에서 다시 계산하며 체력·충돌체·이동·공격 주기·HUD를 동기화합니다. 최대 체력 증가는 자동 회복을 주지 않고, 감소는 현재 체력을 새 최대치에 맞춥니다. 이미 발사된 탄환은 발사 당시 피해·치명타·흡혈을 유지합니다.

`CombatSession`이 공통 피해·실제 흡혈·사망·처치와 실제 플레이용 이벤트를 처리합니다. 확장 기능은 이벤트를 구독하고 다음 전투 틱에 효과를 예약할 수 있습니다. 처치 이벤트는 경험치 지급으로 연결되고, 강화 효과는 같은 스탯 변경 계약으로 적용합니다. API·판정 순서·묶음 공격 규칙과 검증 범위는 [전투 확장 계약](design/COMBAT_FOUNDATION.md)에 기록합니다.

## 구현과 검증 범위

플레이어의 8스탯을 적까지 공통화하고, 60Hz 고정 시뮬레이션에서 플레이어 공격·흡혈·적 접촉 피해·넉백을 계산합니다. HUD·메뉴는 실제 DOM 버튼과 네이티브 dialog이며 키보드 포커스를 관리합니다. `src/ui.ts`가 메뉴·설정·HUD, `src/viewport.ts`가 화면 비율, `src/enemies.ts`가 적 정의, `src/feedback.ts`가 피격·사망 표현, `src/main.ts`가 전투 연결을 담당합니다.

PC의 9:16 화면은 기존 360×640 전장을 유지합니다. 다른 화면 비율은 기본 전장 면적을 기준으로 가로·세로를 조정하되 짧은 변은 360 이상으로 확보합니다. 캐릭터·사거리·이동 속도는 월드 단위로 유지하고 카메라를 균일 확대합니다. 회전 시 몸과 탄환의 상대 위치를 새 경계에 옮기고 충돌을 재정렬합니다. 모바일 가로와 매우 긴 화면에서는 전장 형태나 면적이 달라져 회피·적 밀도 체감이 달라질 수 있습니다.

검증은 고정 전장 전투·군중 충돌·공통 8스탯·단일 적 출현·HUD 통합 테스트를 포함합니다. 공속과 독립적인 공격력별 접촉 피해(0·0.5·1·2), 공격력 0인 적과 다른 적의 동시 접촉, 공통 피격 보호, 기본 탄환 두 대에 사망, 넉백 방향·크기·접촉 변화, 사망 즉시 충돌 제거·0.1초 축소, 동작 감소 페이드와 동일 전투 결과, 연출 정지·재시작도 검사합니다. 고정된 전투 재현 테스트는 명시적인 360×640 경계를 사용하며, 별도 터치 테스트가 실제 화면 비율의 적 80명 충돌과 경계를 검사합니다. 메뉴의 시간 정지·키보드 포커스·탭 복귀·재시작·화면 회전·터치 취소·설정 저장·전체 화면 실패도 검사합니다.

미니멀 효과 개발 시 PC 1440×900, 터치 세로 390×844와 가로 844×390에서 화면을 확인했습니다. 기존 `artifacts/minimal-effects-*.png`는 단일 적으로 단순화하기 전의 개발 기록입니다. 사망 축소 도중 정지 후 가로 회전했을 때 연출 나이와 전투 틱이 유지되고 위치만 새 전장 비율로 이동하는 것도 확인했습니다.

단일 적·체력 2로 단순화한 화면은 [PC](artifacts/basic-enemy-desktop.png)와 [터치 세로](artifacts/basic-enemy-mobile.png)에 보존했습니다. 20초 동안 출현한 28명 모두 같은 스탯(체력 2·공속 0)을 사용했고 브라우저 오류와 가로 넘침이 없었습니다.

2026-11-05 검증: `npm run build` 통과. 전체 122개 테스트 중 121개가 통과했고, 체력 2로 바뀌면서 접촉이 한 번 더 발생하는 재현 시나리오의 기대 체력을 갱신한 뒤 `npx playwright test --last-failed`로 남은 1개도 통과했습니다.

접촉 피해를 적 공격력에 연결한 후 `npx playwright test tests/enemies.spec.ts tests/arena.spec.ts` 39개와 `npm run build`를 통과했습니다. 공격력 0·소수 피해·공속 독립성·동시 접촉·피격 보호를 검증했습니다.

전투 기반 보완 후 신규 27개를 포함한 153개 항목을 검증했습니다. 전체 실행 152개 통과 뒤 새 치명타 이벤트 정보의 비교 범위를 수정하고 관련 36개를 재실행하여 모두 통과했습니다. `npm run build`도 통과했습니다. 공속 60·120·1,000에서 2초간 공격 120·240·2,000회를 보존하며, 스침·작은 적·고속 탄환의 충돌 누락 재현도 해결했습니다. [상세 계약과 검증](design/COMBAT_FOUNDATION.md)을 참고하세요.
