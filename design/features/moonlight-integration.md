# 달빛의 공터 — 실제 플레이 통합

구현 및 Chromium 검증 완료 · 2026-11-06

[디자인 기준서](../DESIGN_BIBLE.md) · [승인된 시안](../dream-concept/README.md)

## 플레이어에게 생기는 변화

접속 즉시 원형 캐릭터가 전투하던 화면을 달빛 타이틀 → 실제 이동·자동 사격 → 강화 선택 → 사망·재시작으로 연결했다. 게임명은 공터서바이버다. 8스탯·기본 적 한 종류·기본 2타 처치·적 공격력에 따른 접촉 피해·피격 보호·경험치·최대 5단계 강화·성장 뒤 새 이동 입력 복귀는 유지한다. 새 무기·적·장애물·기믹·영구 성장·저장은 추가하지 않는다.

## 정보와 조작

- 타이틀은 꿈으로 들어가기 / 환경설정이다. 그림 5종 준비 전에는 버튼을 비활성화한다. 실패하면 다시 시도를 표시하고 부분 로딩으로 전투를 시작하지 않는다. 중복 시작 입력은 무시한다.
- 타이틀 설정은 기존 저장 키를 공유한다. 뒤로가기·Esc·닫기로 타이틀에 복귀하며 전투를 시작하지 않는다. 저장 차단 시 현재 세션에 적용한다.
- 사망과 메뉴 재시작은 바로 새 런, 새로고침은 타이틀이다. DOM 버튼·dialog·포커스 트랩·복귀를 유지하며 타이틀과 결과에서는 전투 입력이 inert다.
- HUD는 좌측 48px 정지, 중앙 시간, 우측 처치, 아래 경험치바와 레벨이다. 체력은 캐릭터 아래 짧은 크림색 막대다. 상세 체력·경험치는 접근성 값만 남긴다.
- 강화 카드는 이름 → 이미지 → 설명 → 별이다. 별은 선택 결과 단계이며 최대 단계는 후보에서 빠진다. 추가 수치와 반복 안내는 없다.

## 같은 세계에서 보이는 방식

청록색 밤·크림색 달빛·회분홍 정지·주아체와 Pretendard를 타이틀·HUD·강화·메뉴·결과에 공유한다. 창틀·기둥·이중 테두리는 추가하지 않는다.

내장 image_gen으로 선택 원본을 편집해 배경·플레이어·적을 각각 제작했다. [자산과 전체 프롬프트](../../public/art/moonlight/manifest.json)에 참조·크기·프레임·앵커·글꼴 출처를 기록한다. 생성 원본은 보존했다. 타이틀과 분홍 붓결은 기존 자산을 복사했다. 전투 배경에는 고정 배우·공격·HUD·문·의자가 없고 이동 영역은 비어 있다.

PNG 합계 약 5.7MB, 로컬 Jua TTF와 Pretendard WOFF2 약 4.2MB다. 글꼴 라이선스를 함께 제공한다. 글꼴이 로딩되지 않으면 시스템 글꼴로 실행한다. 배경은 전장을 채우는 비율로 균일 확대한다. 가로 화면은 배경의 중앙 바닥 부분을 크롭해 이어 붙인 경계를 없앴다. 배우도 균일 배율이다.

## 판정과 상태

원형 물리 객체를 그대로 사용하고 투명하게 그린다. `ArenaPresentation`은 별도 이미지의 위치·배율·각도·방향만 변경한다. 플레이어 높이 36, 적 28 월드 단위에 크기 스탯을 곱한다. 투명 여백은 프레임으로 제외하며 발 앵커는 물리 중심이다. 가까운 배우가 뒤의 배우 위에 그려진다.

이동할 때만 좌우 뒤집기와 최대 1px 상하·2도 기울기를 적용한다. 전투 틱으로 계산해 정지 중 자세를 유지하고 동작 감소에서는 흔들지 않는다. 멈추면 기본 자세로 돌아오고 마지막 수평 방향은 유지한다.

피격은 기존 약한 명도 변화와 넉백이다. 사망 그림은 실제 텍스처·발 앵커·방향을 복제해 풀 객체와 분리하고 100ms 축소 또는 페이드로 제거한다. 회전 시 사망 위치를 변환하며 재시작 시 해제한다. 탄환은 기존 반지름의 크림색 원이다. 추가 파편·광원·흔들림은 없다.

메뉴·강화·포커스·타이틀의 정지 이유를 분리한다. 이동·공격·생성·피격 보호·버프·그림 움직임·사망 효과가 함께 멈춘다. 기존 전투·성장 스냅샷 계약은 유지한다. 개발용 `presentation()`은 화면 상태·그림 위치·크기·방향·각도·객체 수를 읽는다. `simtest`·`stress`는 타이틀을 건너뛰며 `simtest&title=1`은 타이틀 검증용이다. 일반 빌드에는 테스트 API가 없다.

## 검증과 기록

`moonlight.spec.ts`는 타이틀 정지·중복 시작·새로고침, 설정 복귀·공유, 이미지 실패·재시도, 글꼴·저장 실패, 몸/그림 좌표·크기·정지, 동작 감소의 동일 전투, 반복 재시작, 일반 실시간 진입을 검사한다. 기존 사망 테스트는 실제 새 텍스처 이름으로, 일반 진입 테스트는 타이틀 시작을 거치도록 갱신했다.

- 전체 `npm test` 172개가 통과했다. 최종 `npm run build`와 `git diff --check`도 통과했다. 기존 Phaser 번들 크기 경고가 남아 있다.
- 정적 빌드를 Chromium에서 열어 그림 5종과 로컬 글꼴 2종의 로드, 타이틀 시작, 실시간 타이머 진행을 확인했다. HTTP 실패와 페이지 오류는 0건이었고 개발용 테스트 API가 노출되지 않았다.
- 320×568·360×640·390×844·412×915 세로, 844×390 가로, 1440×900 PC에서 타이틀·전투·정지·강화 화면을 캡처했다. 각 화면에서 가로 넘침과 페이지 오류는 0건이었다. 390×844 모의 안전 영역에서는 상단 44px와 하단 34px를 적용해 정지 타깃과 카드 위치를 확인했다.
- 적 80명 배치로 세로와 가로의 배우 구분 및 체력 표시를 확인했다. 군중 압박과 회전에서 전투 경계를 유지하는지는 전체 테스트에 포함된다. 사망 뒤 재시작은 세로·가로에서 2번째 런의 0틱으로 돌아갔다.
- 시안과 실제 캡처를 비교해 타이틀의 달·문·의자 구도, 크림색 정보, 회분홍 정지 면을 확인했다. 전투에서는 분리한 배우가 빈 바닥 위에서 움직이고, 강화 UI와 경험치바는 실제 수치를 반영한다.
- 확인 범위는 Chromium과 터치·안전 영역 모의 환경이다. 실제 휴대폰의 입력과 장시간 플레이 성능은 별도 검증 항목이다.
