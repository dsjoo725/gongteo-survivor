# 꿈속 콘셉트 레퍼런스 조사

작성일: 2026-11-05

## 이번 대화에서 정한 범위

- 주제: 꿈속.
- 사용자 선택 분위기: **익숙하지만 이상한 꿈 — 몽환적이고 약간 불안한 분위기.**
- 작업 순서: 레퍼런스 조사 → 시각 콘셉트 → 대표 화면 시안 → 공통 스타일과 기본 UI 컴포넌트 설계.
- 아래의 팔레트, 공간, UI 방향은 조사에 따른 제안이다. 학교 배경, 게임 제목, 캐릭터 설정, 화풍, 시스템 명칭은 이번 선택만으로 확정하지 않는다.

## 레퍼런스 선정 기준

일상의 형태를 알아볼 수 있으면서 크기·배치·연결 관계가 조금 어긋난 자료를 우선했다. 실제 게임 화면, 작가의 환경 작업, Pinterest 분위기 이미지는 서로 다른 용도로 구분한다. 작품 제목에 Dream이 들어가는 것만으로 채택하지 않는다.

## 1. Superliminal — 익숙한 공간과 비정상적인 크기

- [개발사 공식 사이트](https://www.pillowcastlegames.com/home-horizon)
- [Xbox 공식 소개와 스크린샷](https://news.xbox.com/en-us/2020/07/07/superliminal-is-now-available-for-xbox-one/)
- 유형: 실제 게임 화면.
- 관찰: 분홍빛 벽, 붉은 카펫, 벤치와 액자가 있는 일상적인 실내에 거대한 체스 말이 놓여 있다.
- 참고할 점: 모든 것을 기괴하게 만들지 않아도 익숙한 공간 속 사물 하나의 비율을 바꾸면 꿈처럼 느껴진다.
- 번역 아이디어: 평범한 공터에 지나치게 큰 의자, 문, 가로등 같은 물체 하나를 두는 장면. 게임 적용 시 시야와 충돌 판독은 별도로 검증한다.

![Superliminal의 복도와 거대한 체스 말](https://xboxwire.thesourcemediaassets.com/sites/2/2020/07/superliminal.jpg)

## 2. Dreamcore — 비어 있는 장소의 낯섦

- [Dreamcore 공식 사이트와 스크린샷](https://www.dreamcoregame.com/)
- 유형: 실제 게임 화면.
- 관찰: 수영장, 계단, 복도, 주택과 놀이 공간 등 익숙한 장소를 사람이 없는 공간으로 구성한다. 선택한 수영장 이미지에는 반복되는 타일, 물에 잠긴 계단, 어두운 원형 통로가 보인다.
- 참고할 점: 장식보다 공간의 반복과 비어 있음으로 불안을 만든다.
- 번역 아이디어: 바닥 무늬와 벽의 반복, 어긋난 출입구, 멀리 놓인 사물을 활용한다. 전투 영역의 실제 이동 경계는 명확하게 유지한다.

![Dreamcore 수영장 공식 이미지](https://www.dreamcoregame.com/_next/image?q=75&url=%2Fmap-screenshots%2FDREAMPOOLS%2FD_01.webp&w=3840)

## 3. Pinterest — 구름 위의 일상 공간

- [Dreamcore 실내 이미지 핀](https://www.pinterest.com/pin/19632948394205983/)
- [Backrooms / Dreamcore 참고 보드](https://www.pinterest.com/dkdkdkdk96/backrooms/)
- 유형: 분위기 수집용 이미지·보드. 원작자와 제작 방식은 확인하지 못했다.
- 확인 범위: 이미지 검색 미리보기에서 확인했다. Pinterest 원문 페이지는 접근 제한으로 내용을 열람하지 못했다.
- 참고할 점: 연분홍 실내와 청록색 좌석, 창밖 구름의 조합. 일상 공간과 비현실적인 바깥 풍경의 경계를 참고한다.
- 번역 아이디어: 연한 색을 배경에 한정하고 캐릭터와 위험 요소는 뚜렷하게 분리한다. 지나치게 포근한 구름 장식만으로 분위기를 결정하지 않는다.

![Pinterest에서 발견한 구름 위 실내 이미지](https://i.pinimg.com/originals/2e/b5/0a/2eb50a7920badc807195af87b33df876.jpg?nii=t)

## 4. OMORI — 손그림과 단순한 UI

- [공식 사이트](https://www.omori-game.com/)
- [개발사 Steam 페이지](https://store.steampowered.com/app/1150690/OMORI/)
- [타이틀 화면 이미지가 실린 Game*Spark 기사](https://www.gamespark.jp/article/2026/06/17/168084.html)
- 유형: 실제 게임 UI.
- 관찰: 흰 배경, 연필 질감의 인물과 로고, 검정 직사각형 안의 짧은 메뉴 문구로 타이틀 화면을 구성한다.
- 참고할 점: 강한 장식 패널 없이 그림의 질감과 여백으로 정체성을 전달한다. UI 자체는 단순하고 읽기 쉽다.
- 번역 아이디어: 제목과 일러스트에는 개성을 주고, 시간·체력·버튼 문구는 안정적인 글꼴과 정렬을 사용한다. 원작의 캐릭터·로고·고유 서사는 가져오지 않는다.

![OMORI 타이틀 화면과 메뉴](https://www.gamespark.jp/imgs/p/L_EqOfJ3V1TiFw6lWe7uo28LtgaNBQQDAgEA/1146304.jpg)

## 5. Holly Harris — Dreamcore Pool

- [작가 ArtStation 프로젝트](https://holly95.artstation.com/projects/5Wzmmg)
- 유형: 환경 아트 작업. 게임 UI나 출시 게임 화면으로 분류하지 않는다.
- 작가 설명: 부드러운 파스텔 조명, 안개, 반사와 진주빛 재질로 편안함과 미묘한 낯섦을 표현한 작업이다.
- 참고할 점: 소재와 조명의 조합으로 기억 속 장소 같은 분위기를 만드는 과정.
- 한계: 작가가 생성된 참고 이미지 링크를 명시한다. 프로젝트 자체 전체를 AI 생성 이미지로 단정할 근거는 없다.
- 번역 아이디어: 전장 가장자리의 색과 분위기를 검토할 때 참고한다. 안개나 반사를 HUD 글자와 적의 윤곽 위에 덮는 구현으로 연결하지 않는다.

## 6. Chelsea Pentecost — Dream Realm

- [작가 ArtStation 프로젝트](https://chelseapentecost.artstation.com/projects/kQ6z1n)
- 유형: 대학 과제의 영화 각색용 환경 디자인. 출시 게임 콘셉트 아트로 분류하지 않는다.
- 작가 설명: 끝없이 이어지는 공간과 다른 방으로 연결되는 문, 브루탈리즘 건축과 Carlo Scarpa의 영향을 다룬다.
- 참고할 점: 꿈의 공간을 별·구름 장식 외에 건축의 반복과 연결 관계로 표현하는 방향.
- 번역 아이디어: 문이 다른 장소로 이어지는 장면이나 멀리 반복되는 구조물의 시각 문법. 실제 게임 시스템 추가는 별도 기획 사항이다.

## 7. Emilie Stabell — Realtime Concept Art, Dreams PS4

- [작가 Behance 프로젝트](https://www.behance.net/gallery/72054129/Realtime-Concept-Art-Dreams-PS4)
- 유형: 작가가 게임 Dreams를 위해 제작했다고 설명하는 3D 콘셉트 아트 모음.
- 확인 내용: 2017년에 제작된 작업으로, PS4와 컨트롤러로 만들었다고 명시한다.
- 참고할 점: 자연과 기계가 섞인 조형, 안개 속 실루엣, 현실 재료를 재조합한 세계 표현.
- 번역 아이디어: 배경과 큰 오브젝트의 형태를 참고한다. 현재 꿈속 분위기의 주 참고보다는 조형 확장 참고에 가깝다.

## 조사에 따른 콘셉트 초안

> 기억나는 장소인데, 크기와 배치가 조금씩 틀려 있다.

아래는 사용자 선택 분위기를 구체화하기 위한 제안이며 확정 규격은 아니다.

| 항목 | 제안 | 참고 근거 |
| --- | --- | --- |
| 공간 | 공터·복도·방처럼 익숙한 장소에 비정상적인 사물이나 연결 한 가지 | Superliminal, Dreamcore |
| 색감 | 빛바랜 아이보리·민트·회분홍 바탕에 짙은 먹색으로 대비 | Pinterest 분위기 이미지, OMORI의 명암 분리 |
| 정서 | 처음에는 조용하고 익숙하지만 오래 보면 조금 불안한 느낌 | 사용자 선택, Dreamcore 공간 |
| UI | 얇고 단순한 면, 명확한 정렬, 짧은 문구. 손그림 질감은 제목과 작은 장식에 제한 | OMORI 타이틀 화면 관찰 |
| 움직임 | 배경의 일부만 느리게 변하고 입력 피드백은 즉시 전달 | 생존 전투의 가독성을 위한 설계 제안 |
| 전투 판독 | 플레이어·적·위험 예고·체력을 먼저 읽을 수 있게 처리 | 기존 HUD 분석과 현재 게임의 용도 |

다음 결정은 대표 장면의 조합과 화풍이다. 이를 정한 뒤 타이틀·전투 HUD·정지 메뉴의 대표 화면을 비교하고, 그 결과에서 색·글꼴·버튼·패널·게이지의 규칙을 추출한다. 컴포넌트 라이브러리나 게임 시스템을 이번 조사에서 구현하지 않았다.

- 이번에는 설치와 지침 확인을 완료했다. 후속 UI 시안 단계에서 활용한다. 현재 게임의 런타임 의존성은 추가하지 않았다.

## 자료 사용 범위

이미지는 원문 링크를 연결한 디자인 참고 자료다. 게임에 포함할 제작 에셋으로 채택한 것은 아니다. 작품의 관찰과 우리 게임 적용 제안을 구분하며, 출처가 불명확한 Pinterest 이미지는 분위기 참고로만 사용한다.
