# 아직, 꿈 — UI 컴포넌트 규격 v0.7

> 실제 게임 적용: [달빛 통합 규격](../features/moonlight-integration.md). 아래 표는 정지 시안의 수치다. 실제 게임은 이름 ‘공터서바이버’, 42×6px 숫자 없는 체력바, 경험치바·레벨과 5단계 강화, 로컬 주아체·Pretendard를 사용한다. 시안의 72/100·스탯·고정 조이스틱은 게임 규칙으로 가져오지 않는다.

이 문서는 선택한 3안 ‘달빛의 공터’의 **현행 UI 규격**이다. 세계관·맵·기능 확장의 공통 판단은 [디자인·확장 기준서](../DESIGN_BIBLE.md)를 따른다. 이전 창틀 수치와 색은 [과거 규칙 기록](DESIGN_SYSTEM_HISTORY.md)에 보존하며 현재 화면에 적용하지 않는다.

## 글꼴과 위계

| 역할 | 글꼴 | 크기 / 행간 | 굵기 |
| --- | --- | --- | --- |
| 타이틀 로고 | Jua(주아체) | 56px / 1.25, 좁은 비교 보드 50px | 400 |
| 메뉴 제목 | Jua | 30px / 1.25 | 400 |
| 하위 화면 제목 | Jua | 28px / 1.3 | 400 |
| 생존 타이머 | Jua | 36px / 1.2 | 400 |
| 처치 수치 | Pretendard | 22px / 1.1 | 600 |
| 주요 행동 버튼 | Pretendard | 16px / 1.4 | 600 |
| 본문·설명 | Pretendard | 14px / 1.5 | 400–500 |
| 보조 레이블·체력 수치 | Pretendard | 12px / 1.5 | 500–600 |
| 최소 메타데이터 | Pretendard | 11px / 1.5 | 400–500 |

글자를 줄여 공간 문제를 해결하지 않는다. 한국어를 라틴 대문자 높이에 맞춰 자르지 않으며 버튼 문구는 웹폰트 로드 전 측정값에 갇히지 않게 자연 너비를 사용한다. 일반 수치는 tabular-nums로 정렬한다.

Jua는 Google Fonts, Pretendard는 공식 프로젝트 v1.3.9 동적 서브셋을 현재 시안에서 불러온다. 외부 로드가 차단되면 시스템 글꼴로 대체된다. 제작용 게임에서는 실제 로딩·폴백도 검증한다.

## 색과 표면

| 역할 | 값 |
| --- | --- |
| 밤·메뉴 바탕 | `#244B53` |
| 주 행동 면·메뉴 강조 글자 | `#F6EDD3` |
| 시간·처치 | `#FFF1CF` |
| 보조 글자 | `#C8D6C8` |
| 메뉴 보조 버튼 | `#345E64` |
| 환경 중간색 | `#719D96` 계열 |
| 기억·정지 강조 | `#BF8984` 계열의 페인팅 |

메뉴는 청록색 면에 크림색 글자를 사용하고, 계속하기만 크림색 면과 어두운 글자로 강조한다. HUD는 조용한 밤 배경 위에 크림색 정보와 회분홍 정지 면을 놓는다. 닫힌 HUD 카드·창틀·기둥·이중 테두리를 기본 컴포넌트로 사용하지 않는다.

새 맵은 배경색을 변주할 수 있지만 공통 정보의 역할과 판독성을 유지한다. 위험은 색과 함께 범위·경계·시간 신호로 구분한다. 실제 배경과 효과를 겹친 작은 화면에서 확인한다.

## 간격·크기·정렬

- 간격 단위: **4 / 8 / 12 / 16 / 24 / 32px**.
- 제목과 바로 아래 설명 4px, 제목 묶음과 행동 목록 24px.
- 정지 패널 안쪽 네 면 24px, 버튼 사이 12px, 마지막 버튼과 하단 안내 24px.
- 주요 버튼 높이와 정지 터치 면은 48px. 새 주요 터치 조작에도 이 기준을 적용한다.
- 주요 버튼 좌우 안쪽 여백 16px. 목록의 문구와 우측 아이콘은 공통 선에 정렬한다.
- 버튼 모서리 16px, 정지 패널 28px. 비교 보드의 화면 모서리는 24px이며 모바일 전체 화면에는 인공적인 화면 모서리를 추가하지 않는다.
- 스탯은 이름 왼쪽·값 오른쪽의 공통 두 열이다. 새 행도 같은 템플릿을 사용한다.

## 전투 HUD

| 요소 | 현재 시안 규격 |
| --- | --- |
| 정지 | 좌측 안전 영역 + 12px, 상단 안전 영역 + 12px, 실제 타깃 48×48px |
| 정지 아이콘 | 채운 22px 아이콘, 회분홍 붓결 면, 누름 시 면의 명도 변화 |
| 시간 | 상단 안전 영역 + 12px, 112×48px, 화면 정중앙. 좁은 비교 보드의 슬롯만 100px |
| 처치 | 우측 안전 영역 + 12px, 상단 안전 영역 + 12px, 60×48px, 게임 적의 둥근 실루엣과 숫자 |
| 체력 | 캐릭터 바로 아래, 표시 너비 72px, 막대 6px, 수치 위 간격 4px |
| 조이스틱 시안 | 외곽 84px, 손잡이 32px, 하단 안전 영역 + 56px. 현재는 입력이 없는 시각 시안 |

타이머는 좌우 정보 길이가 달라져도 정중앙에 남는다. 정지 붓자국의 그림 경계와 터치 면을 따로 다루고, 누름 중 실제 타깃·아이콘 위치를 흔들지 않는다. 처치 아이콘은 기존 게임 적의 실루엣을 사용한다. 메뉴 행동 아이콘은 Lucide 16px·1.8px 선을 재사용한다.

## 모바일·안전 영역

- 세로 모바일을 먼저 설계한다. 개별 시안은 가용 뷰포트를 채우고 PC에서는 세로 9:16 화면을 중심에 둔다.
- `viewport-fit=cover`와 `env(safe-area-inset-*)`를 사용한다. 주요 타깃과 글자, 하단 조작을 안전 영역 안쪽에 둔다.
- 배경 크롭/확대와 UI 크기를 분리한다. 현재 전투 페인팅 위쪽은 안전 영역 + 40px 여유를 주고 상단을 밤색 바탕에 페이드한다.
- 현재 장면의 체력 앵커는 이미지의 확대·크롭 좌표에서 계산한다. 실제 게임에 적용할 때는 플레이어 월드/화면 좌표를 따른다.
- 비교 보드는 1200px 이상에서 세 화면, 그보다 좁으면 한 열이다. 350px 미만 호스트의 시안은 너비 288px로 재배치한다.
- 40px 상단 여유, 288px 비교 보드, 현재 이미지 앵커는 시안 구현 값이다. 새 맵의 카메라나 실제 게임 플레이 영역을 이 값으로 고정하지 않는다.
- `--device-safe-*`는 캡처용 안전 영역 모의 변수다. 실제 기기 확인을 대신하지 않는다.

## 상태·메뉴·입력

전투 정보와 메뉴를 중복해 표시하지 않는다. 드래그할 수 없는 패널에 손잡이를 그리지 않는다. 새 상태는 필요한 경우 기본·누름·포커스·사용 불가·선택/열림을 정의한다.

메뉴의 주요 경로는 계속하기 / 플레이어 스탯 / 환경설정 / 다시 시작이다. 하위 화면에서 돌아가기와 Esc, 메뉴 복귀의 포커스 경로를 확인한다. 색 외의 명확한 포커스 표시를 유지한다.

실제 게임에서는 메뉴 진입·포인터 취소·화면 이탈·회전에 이동 입력을 해제하고 전투 전체를 정지한다. 이 문서의 정지 장면과 설정 토글을 실제 전투·설정 저장 구현으로 해석하지 않는다. 자세한 동작은 루트 README와 [전투 확장 계약](../COMBAT_FOUNDATION.md)을 따른다.

## 검증과 후속 작업

모바일 320×568·360×640·390×844·412×915, 안전 영역 모의 값, PC 세로와 지원 가로에서 텍스트·타깃·위험 예고·배경 소품의 겹침을 본다. 상태 전환과 전투를 멈춰야 하는 시간을 함께 확인한다.

현재 시안의 확인 결과와 실기기 등 남은 범위는 [REHEARSAL.md](REHEARSAL.md)에 있다. 새 기능에는 [기능 양식](../templates/FEATURE_BRIEF.md), 새 맵에는 [맵 양식](../templates/MAP_BRIEF.md)을 사용한다.
