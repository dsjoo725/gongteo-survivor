# 꿈속 화면 시안 계획

## v0.7 — 사용자가 선택한 3안 ‘달빛의 공터’ 적용

청록색 달밤·회분홍 문·크림색 달빛의 페인팅을 시안의 기준으로 삼는다. 기존 창틀 HUD를 제거하고 선택한 3안의 조용한 상단 공간에 정지·시간·처치를 배치한다. 전투 배경의 UI를 제거한 정지 장면을 이미지 자산으로 만들고 실제 주아체·Pretendard 텍스트와 메뉴 버튼을 별도로 구현한다. 수치나 조작을 배경에 굽지 않는다. 캐릭터는 선택된 이미지의 작은 여자 캐릭터 그대로 유지한다. 정지 메뉴는 같은 청록색·크림색·회분홍의 단순한 면으로 구성하고 타이틀도 같은 밤의 그림체로 맞춘다. 비교 보드·모바일 전체 화면·안전 영역·48px 정지 타깃·메뉴 진입과 복귀를 확인한다. 실제 게임 로직과 플레이용 스프라이트 분리는 이번 범위가 아니다.

## v0.6 실험 — 폐기

창틀을 문자 그대로 장식 부재로 만든 실험은 사용자가 부자연스럽고 억지스럽다고 거절했다. 기둥·겹테두리·목재 접합을 추가한 변경은 되돌렸다. 이 실험을 후속 디자인의 기준으로 사용하지 않는다.

## 다음 방향 — 게임 아트와 HUD의 공통 표현 탐색

외부 게임 콘셉트 아트와 UI를 참고해 서로 다른 이미지 시안 3종을 비교한다. 기준은 ‘게임의 그림체와 세계관 안에서 자연스럽게 만들어진 느낌’이다. 배경·캐릭터·HUD의 선, 재질, 빛을 함께 설계한다. 창틀을 필수 모티프로 고정하지 않는다. 캐릭터 비율, 여자 캐릭터의 머리/리본/민트 드레스, 좌측 정지·중앙 시간·우측 처치·캐릭터 아래 체력의 모바일 정보 배치는 유지한다. 탐색 방향은 종이/과슈의 낮잠, 직물/솜의 베갯속 꿈, 달빛의 낯익은 공터다. 선택 전에는 새 형태를 기존 인터랙티브 시안에 확정하지 않는다.

## v0.5 — 창틀에 붙은 모바일 전투 HUD

기존 전투·정지 시안의 HUD를 아이보리 창틀, 회분홍 좌측 정지 탭, 중앙의 내려온 시간 판, 우측 기록 띠로 바꾼다. 빛·아래 두께·외곽선과 접합부를 공유한다. 그림 면과 안전 영역 안의 48px 터치 면을 분리한다. 모바일 개별 화면은 가용 뷰포트를 채우며 전장 확대와 UI 크기를 분리한다. 큰 화면의 비교 보드도 유지한다. 주아체·Pretendard와 사용자가 선택한 기존 여자 캐릭터를 유지하고 실제 게임 로직에는 적용하지 않는다. 320×568·360×640·390×844·412×915, 안전 영역 모의 값, 누름·취소·메뉴 진입과 복귀를 확인한다.

## 최신 피드백 — v0.3

stageshow의 가독성·텍스트·간격·정렬 기준을 적용하고 공통 규칙을 DESIGN_SYSTEM.md에 남긴다. 사용자가 지정한 주아체 + Pretendard를 사용한다. 여자 캐릭터는 기존 크기와 얼굴 비율을 유지하며 동화 속 공주 느낌의 웨이브 머리·리본·민트 드레스로 바꾼다. 작은 글자는 11px 이상, 행동 버튼은 48px, 패널 안쪽은 24px, 버튼 사이는 12px를 사용한다. 아래는 이전 시안의 계획 기록이다.

## 최신 피드백 — v0.2

사용자는 HUD 배치에 탕탕특공대를 더 참고하고 전체를 귀엽고 둥글게 바꾸도록 요청했다. 후속으로 기존 명조체를 거절했으므로 제목·버튼·타이머는 주아체로, 보조 문구는 고운돋움으로 바꾼다. HUD는 상단 좌측 정지·중앙 시간·우측 처치, 인물 바로 아래 체력으로 배치한다. 둥근 모서리와 큰 머리의 인물, 부드러운 적 실루엣을 함께 적용한다. 경험치나 재화 시스템은 추가하지 않는다. 아래는 첫 시안 기록이다.

- 범위: 타이틀, 전투 HUD, 일시정지 메뉴의 첫 시각 시안. 실제 게임 로직과 화면은 수정하지 않는다.
- 가제: 아직, 꿈 / STILL ASLEEP. 이름은 제안이며 제품명 변경을 뜻하지 않는다.
- 표현: 파스텔 공간의 단순한 원근과 긴 그림자. 현실적인 문·의자의 비율과 위치를 어긋나게 한다. 게임 내 삽화는 직접 만든 벡터 환경이며 화풍 확정 전의 콘셉트 표현이다.
- 타이틀: 중앙 위의 제목, 중간의 하늘로 열린 문과 거대한 의자, 아래의 진입 버튼. 초점은 문이다.
- 전투: 같은 세계를 위에서 본 공터, 작은 인물과 먹색의 적, 선명한 공격 예고. 체력·시간·처치·정지 버튼만 표시한다.
- 정지: 전투 화면을 고정한 상태에서 아이보리 패널을 올린다. 계속하기가 가장 강하며 스탯·설정·다시 시작이 뒤따른다.
- 형식: 360×640의 세 화면을 비교하는 정지 시안과, 한 화면씩 진입·정지·복귀를 눌러 볼 수 있는 로컬 미리보기. 모바일에서는 각 화면을 세로로 배열한다.
- stageshow 시작 예제: window-row. 동일한 높이의 화면을 나란히 비교하는 구성을 가져오되, 이번 요청은 세 화면 전체를 읽는 것이 목적이므로 가장자리를 자르지 않는다. UI는 Stage와 Button을 사용하고 게임 화면에 브라우저·휴대폰 외곽을 추가하지 않는다.
- 검토: 큰 화면과 390px·320px의 텍스트, 터치 영역, 페이지 넘침, 키보드 포커스, 진입·정지·복귀, 동작 감소. 시각 시안으로 전투 재미·성능·기기 검증을 대신하지 않는다.
