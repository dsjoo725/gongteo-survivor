# 과거 UI 규칙 기록

아래는 현행 규격을 분리하기 전의 원문이다. 현재 작업에는 [DESIGN_SYSTEM.md](DESIGN_SYSTEM.md)와 [디자인·확장 기준서](../DESIGN_BIBLE.md)를 사용한다. 창틀 HUD·과거 타이머 크기·과거 색은 현재 규칙으로 복원하지 않는다.

# 아직, 꿈 — 시안 공통 규칙 v0.7

## 현재 기준: 달빛의 공터

사용자가 3안을 선택했다. 아래의 이전 창틀 수치와 색은 v0.5의 역사적 규격이며 현재 HUD에 적용하지 않는다.

- 세계: 부드럽게 칠한 청록색 밤, 밝은 민트 공터, 회분홍 문, 크림색 달빛. 그림체를 유지한 정지 장면과 별도 UI를 조합한다.
- 색: 밤 `#244B53`, 달빛/주 행동 면 `#F6EDD3`, HUD 숫자 `#FFF1CF`, 회분홍 붓결 면, 메뉴 보조 면 `#345E64`, 보조 글자 `#C8D6C8`.
- HUD: 좌측 정지·정중앙 시간·우측 처치. 상단 안전 영역 + 12px에 놓는다. 정지는 좌측 안전 영역 + 12px, 48×48px. 타이머는 112×48px, Jua 36px/1.2. 처치 면은 우측 안전 영역 + 12px, 60×48px, Pretendard 수치 22px. 사방을 닫는 HUD 카드나 창틀을 두지 않는다.
- 페인팅의 회분홍 붓자국을 정지 면에 사용한다. 입력 시 밝기만 바꾸며 터치 면·아이콘 위치는 유지한다. 처치 아이콘은 기존 게임 적의 둥근 실루엣을 재사용한다.
- 전투 배경의 위쪽은 안전 영역 + 40px만큼 여유를 둔다. 상단을 페이드해 밤색 바탕과 연결하고 달·문이 조작부 아래에서 읽히게 한다. 그림의 확대 배율로 캐릭터 아래 체력을 계산한다. UI 글자·48px 타깃은 배경과 함께 축소하지 않는다.
- 정지 메뉴: 24px 패딩, 12px 행동 간격, 48px 버튼과 28px 모서리를 유지한다. 청록색 표면에 크림색 글자, 계속하기만 크림색 면으로 강조한다.
- 타이틀·메뉴 제목은 Jua, 본문·버튼·스탯은 Pretendard를 유지한다. 선택된 그림의 캐릭터 비율과 점눈을 유지한다.

## 이전 규칙과 검토 이력

기준: `benjitaylor/skills`의 stageshow `craft.md`, `verify.md`, `looks.md`. 둥근 꿈속 콘셉트와 탕탕특공대를 참고한 HUD 배치를 유지하면서 가독성·텍스트 위계·정렬을 정리한다. 이 문서는 시안의 기본 규칙이며 실제 게임의 컴포넌트 API를 확정하지 않는다.

최신 사용자 요구: **모바일 우선 UI·UX**를 제품의 기본 기준으로 삼는다. 가장자리에 붙는 HUD 접합·공통 재질·안전 영역은 [HUD 디테일과 모바일 설계](../HUD_DETAIL_MOBILE_REVIEW.md)를 따라 v0.5 시안에 적용했다. 비교 보드와 브라우저 모의 검증은 실제 폰 입력 검증을 대신하지 않는다.

## 글꼴과 위계

| 역할 | 글꼴 | 크기 / 행간 | 굵기 |
| --- | --- | --- | --- |
| 타이틀 로고 | Jua(주아체) | 56px / 1.25, 좁은 화면 50px | 400 |
| 메뉴 제목 | Jua | 30px / 1.25 | 400 |
| 타이머 | Jua | 30px / 1.2 | 400 |
| 강조 숫자 | Pretendard | 20px / 1.1 | 600 |
| 행동 버튼 | Pretendard | 16px / 1.4 | 600 |
| 본문·설명 | Pretendard | 14px / 1.5 | 400 |
| 보조 레이블·안내 | Pretendard | 12px / 1.5 | 400–500 |
| 최소 메타데이터 | Pretendard | 11px / 1.5 | 400–500 |

한국어에 임의 자간이나 라틴 대문자 높이 기준의 잘림을 적용하지 않는다. 고정 버튼 문구는 자연 너비로 표시해 웹폰트가 늦게 로드돼도 초기 측정 너비에 갇히지 않게 한다. 숫자는 Pretendard의 tabular-nums를 사용한다.

- Jua: Google Fonts.
- Pretendard: [공식 저장소](https://github.com/orioncactus/pretendard)의 v1.3.9 동적 서브셋 CDN.
- 외부 글꼴이 차단되면 시스템 글꼴로 대체한다. 글꼴 적용 확인은 실제 로드된 브라우저에서 수행한다.

## 간격과 정렬

- 간격 단위: **4 / 8 / 12 / 16 / 24 / 32px**. CSS 변수로 정의한다.
- 제목과 바로 아래 설명: 4px. 제목·설명은 한 묶음으로 읽게 한다.
- 제목 묶음과 행동 목록: 24px.
- 버튼끼리: 12px. 버튼 좌우 안쪽 여백은 16px로 통일한다.
- 정지 패널: 위·아래·왼쪽·오른쪽 모두 24px. 메뉴 목록의 모든 문구와 아이콘은 같은 안쪽 선에 정렬한다.
- 메뉴 마지막 버튼과 Esc 안내: 24px.
- 기본 행동 버튼: 높이 48px. ‘계속하기’ 한 개만 진한 채움으로 강조한다.
- HUD: 창틀은 안전 영역 아래에서 시작한다. 정지 터치 면은 왼쪽 안전 영역 + 12px, 위 안전 영역 + 24px, 48×48px이다. 중앙 시간은 위 안전 영역 + 9px, 104×44px이며 화면 정중앙을 유지한다. 처치 글자 면은 오른쪽 안전 영역 + 12px, 위 안전 영역 + 24px, 60×48px이다. 장식 면은 양옆 화면 끝까지 이어진다.
- 스탯: 같은 두 열 템플릿을 공유한다. 이름은 왼쪽, 값은 오른쪽에 정렬한다.

## 모양·아이콘·동작

- 버튼 모서리 16px, 비교 보드 게임 화면 24px, 정지 패널 28px. 개별 전체 화면에는 인공적인 화면 모서리를 넣지 않는다.
- HUD 창틀·시간 판·기록 띠는 아이보리 도장 재질, 정지 탭은 회분홍 면이다. 같은 얇은 외곽선·밝은 윗면·짧은 아래 두께를 공유한다. 정지 누름에서는 그림자와 면색만 바꾸고 타깃·아이콘 위치는 유지한다.
- 행동 아이콘은 Lucide 16×16px·1.8px 선으로 통일한다. 정지 아이콘은 우선순위에 맞춰 20px로 표시한다.
- 드래그할 수 없는 정지 패널에 손잡이 모양을 넣지 않는다.
- 배경의 생존 시간과 중복되는 메뉴 내부 타이머, 위치의 중복 설명, 의미 없는 화면 번호를 제거한다.
- 포커스는 테두리로 표시하며 색만으로 조작 상태를 구분하지 않는다. 메뉴 진입·복귀와 Esc, 미리보기 닫기 후 포커스 복귀를 유지한다.
- 자동 시연은 없다. 동작 감소 환경에서도 모든 화면과 행동이 보인다.

## 반응형

- 1200px 이상에서 세 화면을 나란히 비교한다. 그보다 좁으면 한 열로 쌓아 UI를 작게 축소하지 않는다.
- 비교 보드는 360×640 기준이다. 좁은 호스트에서는 288px 디자인으로 UI를 다시 배치하고 배경만 좌우를 자른다.
- 개별 모바일 화면은 현재 가용 뷰포트를 채운다. 배경은 원래 비율을 유지하며 확대·크롭하고 UI는 고정 CSS px로 배치한다. 캐릭터 아래 체력은 배경 확대 좌표에 맞춰 따라간다. 큰 화면은 세로 9:16 화면으로 가운데 표시한다.
- 안전 영역은 `viewport-fit=cover`와 `env(safe-area-inset-*)`로 처리한다. 노치 아래에 HUD를 두며 조이스틱과 하단 안내는 제스처 영역 위에 둔다. `--device-safe-*` 변수는 캡처 검증용 모의 값으로만 사용한다.
- 메뉴·버튼의 글자 크기를 줄여 맞추지 않는다. 실제 휴대폰과 최종 전투 성능은 별도 검증 대상이다.

## 캐릭터

기존 인물의 머리·얼굴 크기와 장면 배율을 유지한다. 밤색 웨이브 머리, 작은 리본, 민트색 드레스와 둥근 얼굴을 사용해 동화 속 공주를 연상시키는 여자 캐릭터로 표현한다. 타이틀과 전투는 같은 인물 SVG를 공유한다.

후속 사용자 선택: 디즈니 레퍼런스를 더 강하게 적용한 큰 흰자·홍채·속눈썹·입체 음영 시안보다 위의 단순한 v0.3 인물을 선호했다. 캐릭터는 작은 점눈과 볼·리본이 있는 기존 표현으로 복원한다. 주아체 + Pretendard 및 가독성·간격 규칙은 유지한다.
