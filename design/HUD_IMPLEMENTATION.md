# 공터서바이버 HUD 구현 검증

2026-11-05. [설계 검토](HUD_REVIEW.md)의 HUD·메뉴 방향과 후속 요청인 **PC에서도 모바일처럼 세로 화면**을 적용했다.

## 실제 변경

- PC의 마우스 환경은 창 높이에 맞춘 최대 9:16 게임 화면을 중앙에 둔다. 게임 안을 맵이 채우며 별도 하단 페이지 UI를 없앴다. HUD와 메뉴는 브라우저 너비가 아닌 게임 화면 너비를 기준으로 배치한다.
- 터치 환경은 가용 화면을 사용하며 가로 회전을 지원한다. 배경·카메라·스폰·충돌 경계·입력 좌표를 같은 월드 크기에 연결했다. 회전 시 적·주인공·탄환의 상대 위치와 기존 전투 시간을 보존한다.
- 상단에 체력 막대와 현재/최대 값, 생존 시간, 작은 처치 수, 톱니 아이콘과 ‘메뉴’를 표시한다. 초기 조작 안내는 전투 5초 후 사라진다.
- 메뉴에는 계속하기, 플레이어 스탯, 환경설정, 확인 후 다시 시작을 둔다. 8스탯의 실제 값을 표시하고 환경설정은 전체 화면과 피격 효과 감소를 제공한다. 설정은 브라우저에 저장하며 소리가 없어 음량 항목은 만들지 않았다.
- 실제 DOM 버튼과 네이티브 dialog를 사용한다. Tab 포커스 순환, Esc 하위 화면 복귀, 메뉴 종료 후 포커스 반환, 터치 캡처·이동 키 해제를 처리한다.
- 사용자 메뉴·탭 이탈·테스트 정지는 각각의 원인으로 관리한다. 메뉴가 열린 동안 물리·스폰·사격·탄환 수명·피해 쿨다운·피격 연출·생존 시간이 함께 멈춘다. 창 복귀가 열린 메뉴를 해제하지 않는다.
- 기본 피해·사거리·속도·스탯·흡혈·군중 제한은 유지했다. 테스트용 경계 주입은 고정 전투 재현을 위해서만 사용하며 일반 플레이에 노출하지 않는다.

## 자동 검증

| 명령·검사 | 결과 |
| --- | --- |
| `npm test -- --reporter=dot --max-failures=3` | **110개 통과**, 약 2.8분 |
| `npm run build` | TypeScript 검사와 정적 `dist/` 생성 성공 |
| Impeccable detector: `index.html src/style.css src/ui.ts` | 최종 결과 `[]` |
| `git diff --check` | 공백 오류 없음. Git의 LF→CRLF 안내만 출력 |

테스트에는 기존 전투·프레임률 재현·군중 충돌·8스탯과 새 HUD 14개가 포함된다. HUD 테스트는 PC 세로 화면·터치 화면 채우기·메뉴 전체 시간 정지·포커스 순환·이동 키 해제·재시작 확인·창 복귀·회전 중 탄환 보존·설정 저장·전체 화면 실패·터치 취소·가로와 세로의 적 80명 충돌을 검사한다.

## 브라우저 확인

| 환경 | 확인 내용 |
| --- | --- |
| PC 1440×900 | 중앙 게임 화면 약 506.25×900, 360×640 월드. 모바일 형태의 HUD·스탯·설정 |
| 터치 390×844 | 전장 전체 표시, 체력·시간·메뉴 간 겹침 없음, 스탯 내부 스크롤과 복귀 버튼 |
| 터치 844×390 | 가로 전장·원형 비율·터치 좌표·메뉴 내부 스크롤 |
| 터치 320×568 | 페이지 스크롤 없음, 스탯과 설정 내용은 메뉴 안에서 스크롤, 복귀 버튼 유지 |

개발 도구 없는 일반 경로에서 자동 사격으로 처치 3회를 확인했고 메뉴·스탯·설정 이동 중 생존 시간 `00:03`이 유지됐다. 일반 경로에는 `__arenaTest`가 없다. 브라우저 전체 화면 켜기·끄기 후 열린 메뉴 유지도 확인했다. 최종 브라우저 콘솔 오류는 없었다.

`dist/`를 `npm run preview -- --host 127.0.0.1 --port 4177 --strictPort`로 열어 정적 빌드의 시작·메뉴·8스탯·환경설정·재개도 확인했다. 프로덕션에서 `?simtest=1&stress=1`을 붙여도 개발 도구가 열리지 않았다. 누락된 기본 favicon 요청도 자체 아이콘으로 해결했다.

최종 화면 캡처는 `artifacts/hud-final-*`이다. 이전 `hud-after-*`, `hud-review-current-*`는 변경 과정과 이전 화면 기록이며 최종 디자인 기준으로 사용하지 않는다.

## 남은 한계

- PC 9:16은 기존 전장 크기를 유지하지만 터치 가로와 긴 화면에서는 전장 형태·면적이 달라져 회피·적 밀도 체감이 바뀔 수 있다. 이번 검증은 재미·난이도·장시간 밸런스 검증이 아니다.
- Phaser를 포함한 JS 번들은 약 1.39MB, gzip 약 366KB이며 Vite의 500KB 번들 크기 경고가 남아 있다.
- 게임 진행 저장·이어하기, 소리, 성장·장비 시스템은 이번 범위에 추가하지 않았다.
