화면 가장자리에 붙어 있는 HUD

탕탕특공대의 접합·재질을 관찰하고, 꿈속 콘셉트에 적용할 구조를 검토했습니다.

01. 원작에서 관찰한 세 가지 접합

A붙는 방향이 보이는 외곽선

모든 면을 닫아 띄우기보다 화면 끝과 이어지는 면을 둡니다.

B한 재질로 묶는 두께와 빛

어두운 윤곽·밝은 윗면·짧은 아래 두께가 여러 UI에서 반복됩니다.

C읽을 면과 장식 면의 구분

문자와 아이콘의 바탕은 단순하게, 개성은 가장자리와 접합부에 둡니다.

02. 우리 게임의 구조 검토안

현재의 문·의자와 연결되는 아이보리 창틀 + 회분홍 끼움 탭을 추천합니다.

적용할 때 지킬 것

  • 세 조각의 연결부를 먼저 설계하고 같은 선·빛·두께를 공유합니다.
  • 가장자리로 이어지는 장식과 안전 영역 안의 터치 면을 분리합니다.
  • 경험치 시스템이 없으면 긴 진행 바를 추가하지 않습니다.
  • 누르면 아래 두께가 짧아지고, 글자와 이웃의 정렬은 유지됩니다.

03. 모바일을 기본 제품 화면으로

실제 터치 면 48×48 CSS px

프로젝트 제안값입니다. 장식이 잘려도 터치 영역과 문자는 안전 영역 안에 남깁니다.

한 손 이동과 손가락 가림

중앙 전장을 비우고 하단 접점을 확보합니다. UI에서 시작한 터치를 이동에 넘기지 않습니다.

작은 폰부터 검증

320×568부터 긴 폰·노치·주소창 변화를 확인하고 PC로 확장합니다.

원작 관찰은 TapTap(2022)·Uptodown(2023)·Talk Android(2023)의 정지 이미지 기준입니다. 실제 슬라이드 모션과 터치 영역은 확인하지 않았습니다.
