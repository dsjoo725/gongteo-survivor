# 경험치·5단계 강화와 탕탕특공대 참고 HUD

## 적용 범위

2026-11-05 사용자 요청을 반영했다. 적 한 종류·기본 체력 2·공격력 1·공속 0과 미니멀한 전투 효과를 유지하며 처치 경험치와 레벨업 선택을 연결한다. 각 강화는 최신 요청에 따라 최대 5단계다. 강화는 이번 런에만 유지되며 계정 성장·해금·상점·새 무기·새 적은 추가하지 않는다.

## 경험치와 선택

- 플레이어가 적을 처치하면 즉시 경험치 1을 얻는다. 추가 수집물이나 수집 이펙트를 만들지 않는다.
- 공통 처치 이벤트와 적 ID로 중복 보상을 방지한다. 같은 적에 탄환이 겹쳐도 한 번만 지급한다.
- 첫 레벨업은 경험치 5가 필요하며 이후 필요량은 8, 11, 14처럼 3씩 증가한다. 초과 경험치는 다음 레벨로 이월한다.
- 유효한 강화 중 최대 3개를 중복 없이 추첨한다. 성장 난수는 적 생성·치명타 난수와 분리한다.
- 선택 중 전투 틱·적·탄환·넉백·공격 주기·피격 보호·버프 만료·피격·사망 효과가 함께 정지한다. 한 프레임에 여러 틱을 처리하더라도 레벨업한 틱에서 멈춘다.
- 카드 클릭·터치·Enter/Space 또는 숫자 1·2·3으로 고른다. Esc나 배경 클릭으로 건너뛰지 않는다.
- 선택 토큰으로 오래된 카드·중복 입력을 거절한다. 더블클릭의 두 번째 클릭도 다음 보상을 소비하지 않는다.
- 여러 레벨이 한 번에 오르면 보상마다 선택 화면을 순서대로 보여준다. 마지막 선택 뒤 새 방향키 또는 새 전장 터치 드래그가 들어오면 전투를 재개한다.
- 메뉴·포커스 이탈 등 다른 정지 이유가 남아 있으면 재개하지 않는다. 회전과 포인터 취소는 이동 입력을 해제한다.

## 5단계 강화

| 강화 | 단계마다 적용하는 효과 | 5단계 기본값 기준 결과 |
| --- | --- | --- |
| 공격력 | +0.5 | 3.5 |
| 공격 속도 | +0.5회/초 | 5회/초 |
| 치명타 확률 | +5%p | 25% |
| 치명타 피해 | +25%p | 325% |
| 최대 체력 | +1 | 8 |
| 이동 속도 | +15 | 255 |
| 몸집 축소 | ×0.9 | 약 0.59배 |
| 피해 흡혈 | +2%p | 10% |

정확한 수치는 내부 설정과 기존 스탯 메뉴에서 확인한다. 카드에는 전후 숫자나 증감 수치를 표시하지 않는다. 최대 체력 증가는 기존 전투 계약에 따라 자동 회복을 주지 않는다.

강화마다 1~5단계를 저장한다. 카드의 별 다섯 자리에서 얻은 단계는 차분한 금색, 이번에 추가될 한 자리는 밝은 금색과 작은 하이라이트, 남은 자리는 어두운 회갈색으로 표시한다. 5단계 강화는 새 후보에서 제외한다. 끝부분에 남은 종류가 두 개 또는 한 개라면 유효한 카드만 표시한다. 모든 8종을 5단계까지 강화하면 선택을 종료하고 전투를 계속한다. 게이지는 완료 상태가 되며 더 이상 경험치 선택을 반복하지 않는다. 재시작 시 레벨·경험치·별·강화 효과를 초기화한다.

강화는 `CombatSession.upsertModifier`로 적용한다. 후보 생성 때 스탯 검증을 미리 수행하며 거절된 변경은 선택 보상을 소비하지 않는다. 다른 기능이 선택 중 스탯을 바꿔 후보가 무효가 되면 후보를 다시 생성한다.

## 참고 화면과 시각 적용

2026-11-08 ‘달빛이 스민 띠’를 실제 HUD에 적용했다. 18px 무광 청록 띠 안에 8px 금빛 채움과 오른쪽 레벨 숫자를 같은 높이로 배치했다. 직전 바를 채우고 새 레벨과 초과 경험치를 표시하는 전환을 연결한다. [320px 실제 화면](../artifacts/moonlight-strip-live-320.png)

원문 출처는 [Uptodown의 전투·선택 비교](https://blog.en.uptodown.com/survivor-io-requirements-and-how-to-play/), [TapTap 전투 HUD](https://www.taptap.io/vn/post/1740382), [Habby 공식 Google Play 스크린샷](https://play.google.com/store/apps/details?id=com.dxx.firenow&hl=ko)이다.

기존 문서의 ‘현재 없는 경험치 게이지를 추가하지 않는다’는 당시 범위다. 경험치 시스템을 추가하고 캡처를 따라 달라는 최신 요청으로 실제 게이지를 구현했다.

- 상단은 왼쪽 정지 버튼, 가운데 생존 시간, 오른쪽 처치 수다. 아래의 금빛 경험치 게이지 외곽선은 오른쪽 레벨 숫자까지 이어진다. 레벨업 때 직전 바가 약 140ms 동안 차고, 레벨 숫자와 초과 경험치가 새 값으로 바뀐다. 카드가 나타나는 동안 전투는 정지한다. 동작 감소 설정에서는 값과 카드를 즉시 표시한다.
- 체력: 상단 패널 대신 인물 바로 아래의 짧은 바다. 이동·크기 변화·회전에 따라 갱신한다. 아래 경계에서는 잘리지 않도록 위로 옮긴다.
- 전투 중 체력·경험치 상세 숫자는 숨긴다. 스크린리더에 값과 최대치를 제공하며 정확한 스탯은 기존 메뉴에서 확인한다.
- 카드는 **이름 → 그림 → 짧은 설명 → 별 5개** 순서다. 크림색 종이 위에 스탯별 붓그림을 놓는다. 스크린리더는 현재 단계와 선택 결과를 읽는다. [달빛 성장 시안 기록](dream-concept/growth-preview/REHEARSAL.md) · [아트 자산](../public/art/moonlight/manifest.json)
- 전장은 청록색으로 어둡게 덮고 카드 전체를 눌러 선택한다. 누름과 키보드 포커스에 별도 표시를 제공한다.
- 모바일 세로와 일반 PC 세로 전장은 3장을 가로 비교한다. 극도로 좁은 PC 가로 창의 세로 전장에서는 세로 배치하고 모달 안에서 스크롤한다.
